Attention Is All You Need — paper explained

Published on 2017-06-12 · 12 min read

Why the paper mattered

Before 2017, nearly every state-of-the-art sequence model was built on recurrent networks. RNNs process tokens one at a time, which creates two problems: the path between distant tokens is long, so gradients get weak, and the sequential nature of the computation prevents parallel processing of a sequence during training.

The Transformer replaces recurrence entirely with attention. Every position in the sequence can attend to every other position in a single step, so the distance between two tokens no longer affects how easily information flows between them.

Self-attention in one paragraph

Each token emits three vectors: a query, a key and a value. The query of one token is compared against the keys of all tokens to produce a set of attention weights, and those weights define a weighted sum of the values. That sum is the token's new representation, enriched with context from the rest of the sequence.

Multi-head attention runs this process several times in parallel with different projection matrices. One head may learn to track syntactic dependencies while another tracks coreference, and the outputs of all heads are concatenated and projected back into the model dimension.

Positional encoding

Because attention is permutation invariant, the model needs an explicit signal that tells it where each token sits in the sequence. The original paper uses sine and cosine functions of different frequencies, so that the encoding of position p+k can be expressed as a linear function of the encoding of position p. Later models experimented with learned absolute positions and relative position biases.

What followed

BERT, GPT, T5 and essentially every large language model since are direct descendants of this architecture. The recipe scaled, it trained faster than recurrence, and it turned out to be a good fit for accelerators because every token in a sequence can be processed simultaneously.
